# Stories

Uma story por tarefa do [TASKS.md](../TASKS.md), escrita pela skill `story`
a partir de [`.claude/skills/story/TEMPLATE.md`](../../.claude/skills/story/TEMPLATE.md).

- **Arquivo:** `<id>-<slug>.md` — o ID vem do `TASKS.md` com o ponto trocado
  por hífen (ex.: `4.1` → `4-1-comportamento-por-breakpoint.md`).
- **Status:** `TODO` → `IN_PROGRESS` → `DONE` (ou `BLOCKED`), sempre igual na
  story e na linha do `TASKS.md`, que carrega o link para cá.
- O status vive no `TASKS.md` e na própria story; este arquivo só lista.
